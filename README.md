## 📁 Featured Capstone Projects Highlighted

1. **Tesla 2025 Financial Statement Prompt Engineering (LLM Benchmarking):**
   * Benchmarked LLM performance on executing complex financial statement analyses on Tesla’s Form 10-K.
   * Engineered a step-decomposition prompting framework requiring persona assignment, few-shot framing, and explicit output constraints to compute Horizontal, Vertical, and DuPont Ratio metrics.

2. **Source-Grounded Study Notes & Automation Pipeline:**
   * Designed a 3-step sequential automation pipeline utilizing NotebookLM and Claude to transform raw technical disclosures into structured study guides, concept extractions, and active-recall test sets.
   * Achieved an estimated 160-minute time savings across complex academic evaluations.

3. **FinTech Financial Wellness & Savings Target Calculator:**
   * Programmed a Python application processing income streams, fixed expenses, and savings goals to compute remaining disposable income, daily budget thresholds, and expense-to-income ratios with automated safe spending checks.

4. **E-Commerce Database Schema & Aggregation (DECODE Lab):**
   * Structured relational table schemas in PostgreSQL for transaction tracking and authored complex queries with `WHERE` filters and aggregate thresholds.

5. **1,200-Row E-Commerce Exploratory Data Analysis (EDA):**
   * Performed EDA using Pandas and Seaborn to profile datasets, manage missing values, and isolate outliers using IQR and Z-score methods.
